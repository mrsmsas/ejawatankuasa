1. Maklumat sekolah

Maklumat ini dipaparkan pada halaman log masuk, laporan dan surat. Semua boleh diubah kemudian di halaman Tetapan.

2. Surat rasmi

Digunakan oleh Surat Perlantikan dan Surat Panggilan Mesyuarat.

3. Akaun System Admin

Akaun pertama untuk log masuk ke sistem. Kata laluan ini khas untuk sistem ini. Jangan gunakan kata laluan akaun Google anda.

Catat emel dan kata laluan ini. Klik Pasang untuk mencipta pangkalan data.

4. Terbitkan sistem

Satu langkah terakhir. Google memerlukan langkah ini dibuat sendiri oleh pemilik. Abaikan jika anda sudah menerbitkan sistem.

  1. Buka editor Apps Script (tab baharu).
  2. Klik butang biru Deploy di kanan atas, kemudian New deployment.
  3. Pastikan jenis ialah Web app. Jika tiada, klik ikon gear di sebelah Select type dan pilih Web app.
  4. Pastikan Execute as: Me dan Who has access: Anyone.
  5. Klik Deploy. Benarkan kebenaran jika diminta.
  6. Salin Web app URL yang berakhir dengan /exec. Itulah pautan sistem anda.
Pautan hanya boleh diambil daripada kotak Deploy, atau kemudian daripada Deploy ▸ Manage deployments.
Jangan kongsi fail Google Sheet ini. Staf hanya perlukan pautan web. Akaun mereka dicipta di halaman Pengguna selepas log masuk.
